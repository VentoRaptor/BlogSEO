PiPol — Simple Blog Scaffold

This small static site is based on a low-fidelity mock provided by the user.

Files

- index.html — main page
- styles.css — site styles
- assets/article1.svg, article2.svg, article3.svg — placeholder images

Open the site

1. Open `c:\BlogSEO\index.html` in your browser, or run a local static server.

Quick static server (Python 3):

```bash
cd c:\BlogSEO
python -m http.server 8000
# then open http://localhost:8000
```
